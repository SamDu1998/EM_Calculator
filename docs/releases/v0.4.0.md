## EM Calculator v0.4.0

首个全面使用 **C# + WinUI 3** 的 Windows 原生版本。

### 本次更新

- 采用 Windows Mica 背景、原生导航和控件，以及突出核心结果的卡片布局。
- 保留相对带宽、口径效率、波长、传输线阻抗和 SIW 通孔设计五类计算器。
- 传输线支持 Microstrip、CPW、GCPW、Coaxial；不同类型分别保留当前会话输入。
- 支持中英文切换，语言偏好可在重启后保留。
- 将所有公式与单位换算迁入独立 C# 计算库，120 项回归检查通过。
- 移除 Electron、React、TypeScript 和 Python 实现，构建与发布全面使用 .NET。

### 下载与运行

下载 **EM-Calculator-0.4.0-win-x64.zip**，完整解压后运行 `EMCalculator.exe`。请保留随附 DLL、资源和子目录。

此包为 Windows x64 独立包，包含 .NET 和 Windows App SDK 运行时。ZIP 约 66 MiB。此版本不再提供 Linux 构建。

项目目标最低为 Windows 10 1809；当前本地运行验证环境为 Windows 11，Windows 10 与干净机器的运行验证仍待完成。Mica 的显示效果取决于系统版本、主题与透明效果设置。

计算回归检查保留旧版参考数值，并覆盖无效输入、边界与单位换算；它不等同于完整的电磁仿真验证。
