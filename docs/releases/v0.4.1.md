# EM Calculator v0.4.1

Windows x64 自签名 MSIX 试用版。下载附件并解压，按其中的“安装说明.txt”信任开发证书后安装。缺少 Windows App Runtime 时，请先安装包内的 x64 依赖。

- 应用 MSIX 约 41.9 MiB；包含运行时依赖的下载压缩包约 65.4 MiB。
- Windows 管理开始菜单入口和卸载；应用的语言偏好存于应用数据目录。
- 首次启动时会尝试复制旧便携版的语言偏好；卸载不会移除旧便携版数据或手动信任的证书。
- README 新增应用截图。
