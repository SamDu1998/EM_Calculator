# EM Calculator v0.8.0

Windows x64 self-signed MSIX trial. This GitHub release is a prerelease.

## What's new

- Add target-impedance synthesis for Microstrip, CPW, GCPW, and Coaxial lines. CPW/GCPW keep the entered gap fixed; Coaxial solves for inner-conductor diameter.
- Add a Friis link-budget calculator for free-space path loss, received power, and link margin, with a transmitter-to-receiver schematic.
- Run the calculation regression suite before MSIX packaging.

## Install

Download and extract `EM-Calculator-0.8.0-MSIX-trial.zip`. Before installing, verify the certificate thumbprint in `安装说明.txt`, then follow the instructions to trust the development certificate and install the bundled Windows App Runtime if needed. Open `EMCalculator_0.8.0.0_x64.msix` to install.

Certificate SHA-1 thumbprint: `62 E7 98 A7 E1 42 AA 10 FD 68 6E F6 1E 24 96 E3 56 66 3B 3B`.

This package is signed with the project's development certificate, not a public code-signing certificate or Microsoft Store identity. Uninstalling the app does not remove the certificate. Installation on a clean PC and Windows 10 compatibility have not been verified. Friis assumes free-space far-field line-of-sight propagation and matched polarization; any additional known loss must be entered explicitly.
