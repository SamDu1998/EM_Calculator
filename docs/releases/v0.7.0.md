# EM Calculator v0.7.0

Windows x64 self-signed MSIX trial. This GitHub release is a prerelease.

## What's new

- Add a uniform linear-array estimator for element count, spacing, scan angle, phase step, physical spacing, aperture length, and grating-lobe risk.
- Add a bilingual array/scan schematic and group the tool with antenna design.

## Install

Download and extract `EM-Calculator-0.7.0-MSIX-trial.zip`. Before installing, verify the certificate thumbprint in `安装说明.txt`, then follow the instructions to trust the development certificate and install the bundled Windows App Runtime if needed. Open `EMCalculator_0.7.0.0_x64.msix` to install.

Certificate SHA-1 thumbprint: `62 E7 98 A7 E1 42 AA 10 FD 68 6E F6 1E 24 96 E3 56 66 3B 3B`.

This package is signed with the project's development certificate, not a public code-signing certificate or Microsoft Store identity. Uninstalling the app does not remove the certificate. Installation on a clean PC and Windows 10 compatibility have not been verified. The array estimate assumes uniform excitation and identical elements; it does not model element patterns, mutual coupling, gain, or full radiation patterns.
