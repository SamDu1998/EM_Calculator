# EM Calculator v0.5.0

Windows x64 self-signed MSIX trial. This GitHub release is a prerelease.

## What's new

- Add live structure schematics for Microstrip, CPW, GCPW, Coaxial, and SIW via fences.
- Center the content and adapt the calculator between stacked and side-by-side layouts as the available width changes.
- Support Windows display scaling and text scaling, with a startup window size adjusted for the current display scale.
- Fix the unpackaged build configuration so it does not include an MSIX manifest.

## Install

Download and extract `EM-Calculator-0.5.0-MSIX-trial.zip`. Before installing, verify the certificate thumbprint in `安装说明.txt`, then follow the instructions to trust the development certificate and install the bundled Windows App Runtime if needed. Open `EMCalculator_0.5.0.0_x64.msix` to install.

Certificate SHA-1 thumbprint: `62 E7 98 A7 E1 42 AA 10 FD 68 6E F6 1E 24 96 E3 56 66 3B 3B`.

This package is signed with the project's development certificate, not a public code-signing certificate or Microsoft Store identity. Uninstalling the app does not remove the certificate. Installation on a clean PC and Windows 10 compatibility have not been verified.
